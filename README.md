# Sprint_7
Тестирование API сервиса "Яндекс Самокат"

Описание проекта
Этот проект содержит автоматизированные тесты для API сервиса "Яндекс Самокат" с использованием фреймворка PyTest и библиотеки Requests. Тесты проверяют основные функции API, такие как создание и авторизация курьеров, управление заказами и вспомогательные endpoints.

Требования
Для запуска тестов требуются следующие зависимости:

Python 3.7+

PyTest

Requests

Allure-pytest

Faker

Pytest-cov

Установка зависимостей
bash
pip install -r requirements.txt
Запуск тестов
Запуск всех тестов
bash
pytest -v
Запуск тестов с генерацией Allure отчета
bash
pytest --alluredir=allure-results
Запуск конкретных тестов
bash
# Только тесты создания курьера
pytest tests/test_create_courier.py -v

# Только тесты логина курьера
pytest tests/test_login_courier.py -v

# Только тесты заказов
pytest tests/test_create_order.py tests/test_get_order_list.py -v
Генерация отчета Allure
bash
allure serve allure-results
Описание тестов
test_create_courier.py
Тесты для создания курьеров:

✅ Создание курьера с полным набором данных

✅ Создание курьера без имени (успешно)

✅ Нельзя создать двух одинаковых курьеров

✅ Создание курьера без логина (ошибка)

✅ Создание курьера без пароля (ошибка)

test_login_courier.py
Тесты для авторизации курьеров:

✅ Успешный логин курьера

✅ Логин без пароля (ошибка)

✅ Логин несуществующего курьера (ошибка)

✅ Логин без логина (ошибка)

✅ Логин с неверным паролем (ошибка)

test_create_order.py
Тесты для создания заказов:

✅ Создание заказа с разными цветами (BLACK, GREY, оба цвета, без цвета)

✅ Успешное создание возвращает track номер

test_get_order_list.py
Тесты для получения списка заказов:

✅ Получение списка заказов

Ключевые файлы проекта
scooter_api.py
Класс-клиент для работы с API, содержащий методы для всех endpoints:

Создание, логин и удаление курьеров

Создание, принятие, завершение и отмена заказов

Получение списка заказов и информации о заказе

data.py
Содержит:

Метод register_new_courier_and_return_login_password() для генерации уникальных курьеров

Класс Messages с ожидаемыми сообщениями от API

generations.py
Класс для генерации тестовых данных с использованием Faker:

Логины, пароли, имена

Адреса, телефоны, комментарии

Даты и цвета для заказов

urls.py
Константы с URL endpoints API

conftest.py
Фикстуры PyTest:

unique_user - создает уникального курьера для тестов

api_client - экземпляр клиента API

create_unique_user - генерирует данные пользователя

Особенности реализации
Использование параметризации для тестирования различных сценариев

Генерация уникальных данных для избежания конфликтов

Гибкие проверки ответов API

Подробные шаги Allure для удобной отчетности

Обработка различных статус-кодов и сообщений об ошибках
